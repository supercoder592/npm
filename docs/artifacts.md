# 文物圖鑑資料庫（v0.1 數值草案）

> 配合 [GDD.md](GDD.md) 使用。以故宮真實館藏為藍本設計（遊戲內為致敬性重製，非官方授權素材；量產前需確認名稱與形象的授權策略，或改用「神似命名」如「翠玉珍蔬」）。
> 數值意義：**名氣** 1–5★（吸引力基值 20/35/55/80/110）；**劣化/日** 為普通展櫃、無環控下的每日品質流失；**購藏價** `—` 表示開局持有或劇情取得，不可購買。

## 屬性速查

- **類別**：陶瓷｜書畫｜青銅｜玉石（對應 GDD 4.4 的四套專屬工序）
- **常見病害**：該文物開局或劣化時會出現的病症池（檢視建檔要找的目標）
- **關鍵工序**：修這件文物的玩法重心
- **修復難度**：★1–5，影響失誤閾值與所需證照等級（★4 需乙級、★5 需甲級）

## E. 病害 → 工具/材料 對照表（正解表，平衡基準）

| 病害 | 正解工具/材料 | 陷阱選項（可選但有後果） |
|---|---|---|
| 積塵 | 軟毛刷 | 濕布（書畫上=洇損） |
| 油汙 | 棉籤＋專用溶劑 | 酒精直擦（釉彩/顏料層受損） |
| 霉斑（書畫） | 棉籤點拭＋除霉劑、控濕 | 硬刷（撕裂紙纖維） |
| 粉狀綠鏽（青銅病） | 倍半碳酸鈉浸泡＋手術刀精修 | 打磨機（連皮殼一起磨掉=除鏽過度醜聞） |
| 穩定皮殼 | **不處理**（最小干預加分） | 任何除鏽（品質+倫理雙扣） |
| 碎裂 | 斷面比對＋B-72 黏合 | 快乾膠（隱患：7 日後崩開） |
| 缺損 | 石膏/漆灰補配＋略淺全色 | 環氧樹脂＋全等色（倫理 F＋隱患） |
| 微裂隙（玉/瓷） | 透光檢測＋微量注膠 | 超音波清洗（碎裂事故） |
| 命紙老化 | 潤濕揭裱＋澱粉漿糊托新紙 | 乾揭（撕裂畫心=醜聞） |
| 變形（青銅） | 恆溫加熱台＋緩慢矯形 | 冷敲（斷裂） |
