## 1. 遊戲概述

### 1.1 一句話賣點

**「白天你是拿手術刀的文物醫生，晚上你是算門票的博物館館長——而嘉義那間分院，正在搶你的觀光客。」**

### 1.2 遊戲概念

玩家是故宮北部院區的資深修復師，因館長懸缺臨危受命「兼任館長」。你必須：

- 以**第一人稱**在館內自由走動：巡展廳、進修復室、上辦公室、下庫房；
- 用**深度擬真的修復工序**搶救劣化與受損的國寶，維持展品品質；
- 品質與名氣吸引**觀光客**，門票與文創收入養活整個院區；
- 把賺來的錢投資在購藏、設備、人事與行銷上；
- 與**電腦操控的南部院區**即時競爭，每日結算比拚觀光客數與聲望，30 天一季分出勝負。

### 1.3 遊戲類型與參考作品

| 面向 | 參考作品 | 借鑑重點 |
|---|---|---|
| 修復手感 | PowerWash Simulator、House Flipper | 「把髒東西弄乾淨」的療癒回饋、第一人稱工具操作 |
| 工序深度 | 潛淵症手術 mod、Wilmot's Warehouse 的專注感 | 多步驟、選錯工具有後果 |
| 經營層 | Two Point Museum、過山車大亨 | 展位佈置、遊客模擬、收支平衡 |
| 壓力節奏 | Papers, Please | 「時間有限、事情做不完」的取捨張力 |
| 復古視覺 | Crow Country、Mouthwashing | PSX 風低解析 3D 的現代化運用 |

### 1.4 目標玩家

- 喜歡模擬經營與「整理／清潔／修復」療癒系玩法的玩家（25–45 歲為主力）；
- 對故宮文物、文化資產有興趣的族群（含教育市場：博物館學、文資系所）；
- 喜歡「一局 3–5 小時、可重開不同策略」的 Roguelite 式經營玩家。

### 1.5 平台與規格（目標）

- 首發：PC（Steam）；次要：Mac。
- 單人遊玩（對手為 AI），全程離線。
- 一季（30 遊戲日）約 3–5 小時；支援季後無盡模式。

### 1.6 設計支柱（Design Pillars）

1. **修復是主菜，經營是火候**——修復小遊戲必須好玩到可以單獨成立；經營層決定你「修什麼、先修誰」。
2. **每個選擇都有機會成本**——時間是最稀缺資源：你在修復台上的每一分鐘，展廳裡就有別的文物在劣化、南院在賺錢。
3. **尊重真實修復倫理**——最小干預、可逆性、可辨識性不是說教，而是計分規則。
4. **高自由度、低懲罰重開**——不設固定劇本；失敗一季也能帶著技能與圖鑑進度重開。

## 2. 美術與視聽方向

### 2.1 「像素復古 × 第一人稱」的解法：PSX 風低解析度 3D

純 2D 像素難以承載第一人稱自由走動，因此採用 **PSX / PS1 世代風格的 3D**，它在玩家認知上就是「像素復古」的 3D 版本：

- **低面數模型**：文物與場景皆低多邊形（單一文物 300–800 面），輪廓優先、細節交給貼圖。
- **低解析像素貼圖**：64×64 / 128×128 貼圖、關閉雙線性過濾（point filtering），近看有明顯像素顆粒。
- **低解析渲染**：內部以 480p（或 640×360）渲染後放大到全螢幕，可於選項切換「復古／清晰」。
- **固定調色盤與抖動漸層**（dithering）：全遊戲統一 64 色主調色盤，漸層用抖動點陣呈現。
- **頂點抖動與仿射貼圖**（可選開關）：重現 PS1 的抖動晃動感，預設弱化以免暈眩。
- **修復特寫例外**：進入修復台特寫時解析度提升一級（細節看得清才玩得下去），但仍維持調色盤與像素貼圖語彙。

### 2.2 色彩與場景語彙

- **北院（玩家）**：故宮北院的宮殿意象——米黃牆、青綠琉璃瓦、朱紅柱、石獅、正廳挑高展廳；室內暖黃展櫃光、深色木紋。
- **南院（AI，僅出現於結算畫面與新聞插圖）**：現代流線建築意象、水景、冷色玻璃，與北院形成視覺對比。
- **展廳照明**：文物用聚光燈、環境低照度，品質高的文物微微「發光」（拉高自發光值），品質差的文物貼圖疊加汙漬/裂紋 decal，一眼可讀。
- **修復室**：無影燈、白色工作檯、工具牆，與展廳的暖色形成「手術室」對比。

### 2.3 UI 風格

- 全 UI 採像素字體（中文採 12/16px 點陣字），視窗為仿舊式作業系統的檔案夾／表單風（呼應「建檔、公文」的館務感）。
- HUD 極簡：準星、互動提示、資金／日期／訪客數三格；其餘資訊全部收進「館長手冊」（Tab）。

### 2.4 音樂音效

- 配樂：**國樂器採樣 × chiptune** 混搭（古箏/笛/南胡旋律＋8-bit 節奏），展廳靜謐版、修復室專注版、結算日輕快版。
- 修復音效是體驗核心：刷子沙沙、手術刀刮擦、超音波嗡鳴、瓷片「喀」一聲對上的手感音——全部做細。
- 失誤音（裂一聲）刻意做得令人心頭一緊。

## 3. 核心循環

### 3.1 一「日」的結構（即時制）

一遊戲日 = 現實約 8 分鐘（可在設定中調 6–12 分鐘），分三段：

```
 開館前(1min)      開館中(6min)                    閉館結算(1min)
┌───────────┐  ┌──────────────────────────────┐  ┌────────────┐
│ 看報表/公文 │→│ 巡館・修復・佈展・採購・突發事件 │→│ 收支+南北院PK │
│ 排今日計畫 │  │ （時間即時流動，訪客持續進出）    │  │ 新聞頭條     │
└───────────┘  └──────────────────────────────┘  └────────────┘
```

- **開館前**：讀「今日文物健檢報告」（哪些文物劣化警戒）、南院動態情報、公文事件選擇。
- **開館中**：完全自由。你可以整天泡在修復室、也可以整天佈展搞行銷——但沒人修文物品質就持續下滑。
- **閉館結算**：當日訪客數、收入支出、聲望變化、南北院即日排名，以「晚間新聞」畫面呈現。

### 3.2 核心循環圖

```
        ┌────────────────────────────────────────┐
        │                                        ▼
   文物劣化/受損 ──► 第一人稱巡館發現 ──► 送修復室深度修復
        ▲                                        │
        │                                        ▼
   時間流逝 ◄── 投資(購藏/設備/人事/行銷) ◄── 品質↑ → 吸引力↑
        ▲                                        │
        │                                        ▼
        └──────── 每日結算 & 南北院PK ◄── 觀光客 → 門票/文創收入
```

### 3.3 中期循環（一季 30 天）

- 第 1–5 天：教學融入劇情（前館長留下爛攤子：三件文物待修、資金見底）。
- 第 6–29 天：自由經營，每 5 天一次「週評鑑」（文化部評鑑員來訪，給聲望加減分），每 7–10 天一次大型事件（特展邀請、颱風、國寶爭議）。
- 第 30 天：**雙十文化週決戰日**——訪客潮加倍，當日表現權重 ×3，結束後總結算定勝負。

## 4. 深度修復系統（核心玩法）

### 4.1 設計原則

- 真實修復工序的**遊戲化擬真**：步驟、工具、材料、倫理全部取材自真實文物保存科學，但操作節奏遊戲化（單件修復 3–10 分鐘）。
- **沒有 QTE、沒有時間條逼迫**——壓力來自「外面的世界還在動」：你修得越久，展廳品質掉越多、南院賺越多。
- 每一步都可以**提早收手**（符合「最小干預」），修到 70 分就出去也是合法策略。

### 4.2 文物狀態模型

每件文物有以下屬性（詳見[文物圖鑑](artifacts.md)）：

| 屬性 | 說明 |
|---|---|
| 品質 Quality（0–100） | 展示吸引力的主要係數；<40 會被媒體點名、<20 強制下架 |
| 病害列表 Conditions | 具體病症（積塵、鏽蝕、斷裂、霉斑、褪色…），每個病害壓低品質上限 |
| 劣化速率 Decay | 每日品質流失，受材質、展櫃等級、恆溫恆濕設備影響 |
| 名氣 Fame（1–5★） | 天生吸客力；鎮館之寶 5★ |
| 修復履歷 | 歷次修復紀錄，影響專家評鑑與轉賣/借展價值 |
| 隱患 Hidden Risk | 用錯材料或過度修復留下的隱藏計時炸彈（見 4.6） |

### 4.3 六道工序（通用骨架）

進入修復室，把文物放上工作檯後，依序（可跳過不需要的步驟）：

| # | 工序 | 玩法概述 | 失誤風險 |
|---|---|---|---|
| 1 | **檢視建檔** | 手持紫外燈/放大鏡掃描文物表面，找出所有病害點並拍照建檔（找碴玩法）。漏檢的病害會在後續工序中「突襲」 | 漏檢 → 後續工序中途跳出未知病害，打亂計畫 |
| 2 | **清潔除垢** | 依病害選工具（軟毛刷/棉籤+溶劑/超音波/雷射），以滑鼠塗抹清除汙層。不同汙垢對應不同工具，用錯=無效或傷害本體 | 力道過猛（滑鼠速度過快）刮傷本體；溶劑選錯造成化學損傷 |
| 3 | **拼接復位** | 碎片文物：3D 檢視旋轉碎片、找對應斷面、按正確順序黏合（順序錯了會「關門」——後面的碎片放不進去，需拆重來） | 順序錯誤浪費黏合劑與時間；強行按壓造成新斷裂 |
| 4 | **補配缺損** | 對缺失部位調配補料（石膏/樹脂/漆灰…），雕塑填補外型。補太多=過度修復扣倫理分 | 補料配比錯誤 → 日後開裂（隱患） |
| 5 | **全色接筆** | 調色盤混色補繪，色彩需接近但**依可辨識性原則刻意略淺**。玩家自行拿捏「像不像」與「倫理分」的平衡 | 調色全等於原色 → 專家評鑑判「作偽嫌疑」扣聲望 |
| 6 | **封護養護** | 選封護材料（是否可逆！）均勻噴塗，決定新的劣化速率 | 不可逆材料短期加分、留下永久隱患 |

**完成評分**：品質恢復量 ＝ 工序完成度 × 工具/材料正確率 × 技能加成；另給「倫理評分」（S/A/B/C/F），影響週評鑑聲望。

### 4.4 四大類別的專屬工序差異

#### 陶瓷（例：汝窯水仙盆、嬰兒枕）
- 重點工序：拼接復位（招牌玩法）、石膏補配、仿釉全色。
- 特色機制：**斷面比對**——特寫模式下旋轉兩塊碎片，斷面紋理吻合才能點膠；金繼（描金）為可解鎖的高倫理替代方案（缺損可辨識又美觀，倫理S）。
- 大忌：502 式快乾膠（不可逆材料，商店裡就是有賣，便宜又快——陷阱選項）。

#### 書畫（例：快雪時晴帖、富春山居圖）
- 重點工序：**揭裱**（把畫心從舊命紙上「揭」下來——長按緩慢拖曳，手抖即撕裂，全遊戲最緊張的操作）、除霉除斑（棉籤點拭）、接筆全色（毛筆補繪）。
- 特色機制：濕度計時——噴水潤紙後有一段「可操作窗口」，太乾揭不動、太濕會洇墨。
- 大忌：直接用水洗、用硬毛刷。

#### 青銅（例：毛公鼎、散氏盤、宗周鐘）
- 重點工序：**除鏽分類**——有害鏽（粉狀綠鏽=青銅病，必除）vs 無害鏽（穩定皮殼=歲月價值，除了反而扣分）。檢視建檔時判別鏽種是玩家知識的試金石。
- 特色機制：機械除鏽（手術刀刮，力道控制）vs 化學除鏽（倍半碳酸鈉浸泡，隔日才見效——時間管理）；矯形（加熱+緩慢施壓推回變形）。
- 大忌：把整件除得金光閃閃（「除鏽過度」是聲望重傷事件）。

#### 玉石（例：翠玉白菜、肉形石、玉辟邪）
- 重點工序：微裂隙檢測（透光掃描）、滲透加固（注膠進裂隙，注量控制）、拋光（畫圈打磨，轉速與時間控制）。
- 特色機制：**沁色保護**——玉的沁色是價值，拋過頭會把沁色磨掉（品質反降）。
- 大忌：超音波清洗有裂隙的玉件（直接碎給你看）。

### 4.5 工具與材料系統

**工具牆（隨進度解鎖/購買）**：

| 工具 | 用途 | 等級演進 |
|---|---|---|
| 軟毛刷/羊毛排刷 | 除塵 | 基礎 → 靜電除塵刷 |
| 棉籤＋溶劑組 | 局部清潔 | 水 → 酒精 → 專用溶劑組 |
| 手術刀/竹刀 | 機械除鏽、剔補料 | 鈍刀 → 精密刀組（失誤率↓） |
| 超音波清洗機 | 金屬小件批次清潔 | 不可用於陶瓷裂件/玉裂件 |
| 雷射除鏽儀 | 高階除鏽，快且準 | 季後期高價設備 |
| 紫外燈/紅外攝影 | 檢視建檔，看見隱藏病害/舊修復 | 解析度逐級提升 |
| 恆溫加熱台/矯形具 | 青銅矯形 | — |
| 毛筆組＋礦物顏料 | 全色接筆 | 顏料庫逐步擴充 |

**材料學與可逆性原則**（貫穿全遊戲的核心知識）：

| 材料 | 可逆性 | 特性 |
|---|---|---|
| Paraloid B-72 | ✅ 可逆 | 萬用黏合/封護，標準答案，稍貴 |
| 魚膠/動物膠 | ✅ 可逆 | 書畫、傳統工藝適用，需加熱調製（多一步） |
| 小麥澱粉漿糊 | ✅ 可逆 | 揭裱托紙專用 |
| 石膏 | 半可逆 | 陶瓷補配標準 |
| 環氧樹脂 | ❌ 不可逆 | 強度高、便宜、快——但留隱患，倫理扣分 |
| 快乾膠 | ❌ 不可逆 | 最便宜最快的陷阱選項，隱患極大 |

### 4.6 修復倫理與隱患系統

- **倫理三原則計分**：最小干預（做了不必要的工序扣分）、可逆性（材料選擇）、可辨識性（全色色差）。每次修復產出倫理評分，累積成「修復師風評」。
- **隱患（Hidden Risk）**：不可逆材料或錯誤配比不會立刻懲罰——它埋一顆 3–10 天後引爆的地雷（補料開裂、黏合面崩開、封護層泛黃），屆時品質暴跌並上新聞。短視 vs 長遠是本作的核心抉擇。
- **醜聞事件**：修復中重大失誤（撕裂畫心、碎裂玉件）觸發「文物受損」新聞，聲望大扣、文化部評鑑降級；一季 3 次醜聞 = 直接敗北（撤職結局）。

### 4.7 委外與助手

- 玩家分身乏術時，可將文物**委外修復**（花錢、品質恢復量普通、無倫理分）或交給**助手修復師**（見 9. 人事）處理低星文物；鎮館之寶只有玩家親手修才能拿高分——確保核心玩法始終在玩家手上。

## 5. 經營系統

### 5.1 收入

| 來源 | 說明 |
|---|---|
| 門票 | 訪客數 × 票價（玩家可自訂 50–300 元；票價過高壓低來客意願） |
| 文創商店 | 訪客滿意度轉化：滿意度越高，人均消費越高；可投資開發「爆款文創」（翠玉白菜傘、肉形石護唇膏） |
| 特展收入 | 接受借展/策劃特展事件的一次性大額收入 |
| 政府補助 | 每週評鑑等級決定的固定撥款（評鑑差會被砍預算） |

### 5.2 支出

| 項目 | 說明 |
|---|---|
| 修復材料/工具 | 每次修復消耗材料費；工具一次性購置 |
| 人事薪資 | 助手修復師、導覽員、保全，每日發薪 |
| 設備維護 | 恆溫恆濕、展櫃、安防系統的購置與日常維護費 |
| 行銷 | 廣告投放（隔日見效）、網紅邀請（當日爆量但滿意度風險） |
| 購藏 | 拍賣會/徵集購入新文物（與南院競標！見 6.4） |

### 5.3 觀光客模擬

訪客為簡化個體模擬（agent）：從大門進場 → 依「吸引力權重」挑 3–6 件文物觀賞 → 逛文創店 → 離場，全程可在第一人稱視野中看到（像素小人擠在翠玉白菜前是重要的視覺回饋）。

- **來客量**由館區總吸引力、票價、行銷、星期/事件係數決定（公式見 11.2）。
- **滿意度**由觀賞文物的平均品質、動線擁擠度、設施（休息椅、導覽）決定，影響文創消費與次日口碑係數。
- 品質 <40 的文物會讓訪客顯示「失望」表情泡泡並扣滿意度——爛文物擺著比收進庫房更傷。

### 5.4 展廳與佈展（自由度重點）

- 北院可用空間：正廳（8 展位，含 2 個**黃金展位**：吸引力 ×1.3）、東西側廳（各 6 展位）、後期可解鎖新翼樓（+8 展位）。
- 玩家可**第一人稱搬運文物**（推著文物運送車）自由決定：哪件放黃金位、哪件收庫房、動線怎麼排。
- **主題佈展加成**：同類別文物相鄰展出觸發「主題展」加成（例：三件青銅相鄰 = 「吉金特區」吸引力 +15%）。
- 展櫃分級：普通櫃 → 恆濕櫃 → 低反射恆溫櫃，逐級降低劣化速率。

## 6. 南北院 PK 系統

### 6.1 對戰框架

- 南院是一個**完整鏡像的模擬經濟體**（有自己的館藏、資金、聲望、劣化與修復），但不做 3D 場景——玩家透過「情報」與「新聞」感知它。
- 雙方即時並行：你在修文物的每一秒，南院的模擬時鐘也在走。

### 6.2 每日結算畫面（晚間新聞）

閉館後以像素電視新聞畫面呈現：

1. 今日兩院訪客數、收入對比長條圖；
2. 頭條事件（誰家出包/誰家出爆款，動態產生）；
3. 累計**聲望分**與目前排名；
4. 南院明日動向情報（模糊提示：「南院近日大量採購除鏽設備…」——供玩家預判）。

### 6.3 聲望計分（勝負標準）

```
每日聲望 = 訪客數/10 + 平均展品品質×0.5 + 滿意度加成 + 事件加減分
週評鑑：文化部評分（品質、倫理風評、醜聞紀錄）→ 額外聲望與補助款
季末（第30天）：累計聲望高者勝
```

結局分歧：大勝（領先 >30%）＝「升任總院長」；小勝＝連任；小敗＝留院察看；大敗或 3 醜聞＝撤職（並解鎖「南院劇本」新遊戲+模式的伏筆）。

### 6.4 南院 AI 行為模型

AI 不作弊（與玩家同規則同公式），以「性格化策略」呈現：

- **決策層（每日一次）**：依當前狀態在「修復／購藏／行銷／設備」間分配預算，權重由 AI 性格決定。
- **三種可選 AI 館長性格（開局選擇對手）**：
  - 「學者型」：重修復與倫理，聲望穩定成長，少爆點——適合新手。
  - 「網紅型」：重行銷與文創，來客暴衝但品質崩壞風險高——中等。
  - 「鐵腕型」：均衡且會在拍賣會與你搶文物、挖角你的助手——困難。
- **Rubber-banding（可關閉）**：落後方獲得小幅補助款加成（±10% 內），維持整季張力；預設開、純粹主義者可關。
- **可感知的 AI**：AI 的每個大動作都會化為新聞/情報讓玩家看見，輸贏都輸贏得明白。

### 6.5 直接互動點

- **拍賣會（每 5 天）**：南北院同場競標新文物，即時舉牌喊價；
- **挖角**：雙方可出高薪挖對方助手（觸發忠誠度事件）；
- **借展談判**：南院偶爾來借你的鎮館之寶（借出=收租金但自家吸引力下降，拒絕=南院聲望攻擊新聞）。

## 7. 高自由度設計

### 7.1 非線性目標

除了季末聲望勝負，不設任何強制任務。開館中的 6 分鐘你可以：

- 整天窩修復室把毛公鼎修到 100 分；
- 完全不修，把錢全砸行銷與文創（品質會爛，但短期收入暴衝）；
- 專心佈展搬文物調動線；
- 跑去庫房翻出前館長封存的「待鑑定箱」（開箱玩法：可能是贗品、可能是遺珠）；
- 提前閉館（犧牲當日收入，換取無訪客干擾的整修時間）。

### 7.2 策略路線（皆可通關）

| 路線 | 玩法 | 風險 |
|---|---|---|
| 修復大師流 | 全品質 90+、倫理全 S，靠評鑑與口碑滾聲望 | 前期收入慢，怕南院行銷流搶量 |
| 商業行銷流 | 低票價衝量、爆款文創、網紅營銷 | 品質下滑、醜聞機率高 |
| 收藏擴張流 | 拍賣會搶購名氣文物、以量取勝 | 資金鏈緊、修復量能吃緊 |
| 特化策展流 | 集中單一類別做主題特展加成 | 該類別材料漲價事件會重傷 |

### 7.3 自由度邊界（刻意的限制）

- 文物**不可出售**（你是館長不是古董商）——只能借出、入庫、展出；
- 醜聞上限與強制下架線，防止玩家徹底擺爛還能贏；
- 每日行動不限次數，但**身體只有一個**：所有操作都要第一人稱走到現場，走位本身就是資源。

## 8. 第一人稱操作與 UI/UX

### 8.1 鍵位（PC）

| 按鍵 | 功能 |
|---|---|
| WASD / 滑鼠 | 移動 / 視角 |
| E | 互動（檢視文物、上修復台、開門、撿取） |
| R | 搬運/放下文物（推運送車） |
| Tab | 館長手冊（館藏總覽、財報、情報、技能、設定） |
| Q | 快速切換手上工具（修復模式中為工具輪盤） |
| 滑鼠左鍵 | 使用工具（塗抹/刮/點拭/拖曳碎片） |
| 滑鼠右鍵（長按） | 精細模式（移動速度減半、失誤率降低——修復緊張段落的「屏息」操作） |
| Esc | 離開特寫/選單 |

### 8.2 修復台特寫

- 按 E 上修復台 → 鏡頭推進到工作檯俯視/斜視特寫，解析度提升一級；
- 左側工序清單（可自由跳序）、右側工具牆、下方材料抽屜；
- 文物可滑鼠拖曳旋轉（3D 檢視），滾輪縮放；
- 隨時 Esc 收工，進度保留（半成品狀態的文物可先送回展廳——品質部分恢復）。

### 8.3 資訊呈現

- 展廳中望向文物：浮現極簡狀態牌（名稱、品質條、警示圖示）；
- 品質視覺化不靠數字也可讀：汙漬 decal、裂紋、燈光亮度三層表現；
- 每日開館前的「健檢報告」是玩家的 to-do list 來源，但不強制照做。

### 8.4 教學設計

- 第 1–3 天以「前館長留下的爛攤子」帶三場教學修復（青銅除鏽 → 書畫除霉 → 陶瓷拼接），每場只教一類工序；
- 倫理系統不教條化：第一次用快乾膠時，老技師助手只會幽幽說一句「……當年老王也是這樣開始的」，後果讓玩家自己踩。

## 9. 進度與成長

### 9.1 修復師技能樹（三系）

| 系 | 代表技能 |
|---|---|
| 巧手系 | 失誤閾值放寬、精細模式時間加長、拼接自動提示斷面 |
| 學識系 | 檢視建檔自動標記部分病害、鏽種辨識提示、材料費折扣 |
| 館務系 | 走路速度、助手效率、行銷效果、拍賣會加價幅度 |

技能點來源：修復完成（倫理分越高給越多）、週評鑑、事件獎勵。

### 9.2 證照等級

修復累積經驗提升「文物修復師等級」（丙級→乙級→甲級→人間國寶），逐級解鎖高階工具（雷射除鏽儀）、高難度文物（一級國寶需甲級才能親手修）。

### 9.3 跨季繼承（Roguelite）

一季結束後開新局可繼承：圖鑑進度、技能樹的 30%、解鎖的 AI 性格與劇本——鼓勵多策略重開。

| 事件 | 觸發 | 效果與選擇 |
|---|---|---|
| 颱風來襲 | 每季 1–2 次，前一天預報 | 選擇閉館防災（損失收入）或照常開館（漏水機率損傷文物） |

| 學生校外教學 | 隨機 | 當日訪客+滿意度規則變化（吵鬧扣一般訪客滿意度） |

| 老技師的考題 | 技能樹進度觸發 | 限定條件修復挑戰（只准用傳統材料），成功=大量技能點 |

## 11. 數值草案與公式

### 11.1 初始盤面

- 玩家北院：資金 50,000、館藏 5 件（見圖鑑：翠玉白菜、肉形石、毛公鼎、汝窯水仙盆、快雪時晴帖，其中 3 件帶病害）、助手 1 名、票價預設 150。
- 南院 AI：資金 50,000、館藏 5 件（名氣總和相同、病害較輕但無 5★ 鎮館寶）——雙方起點等值、結構不同。

### 11.2 核心公式（草案，實作時平衡）

```
文物吸引力 = 名氣基值 × (品質/100)^1.2 × 展位係數 × 主題展加成
館區吸引力 = Σ 展出文物吸引力 × 口碑係數(前3日滿意度均值 0.8~1.2)
當日來客  = 基礎人流 × 館區吸引力指數 × 票價彈性(150元=1.0，每+50元 ×0.88) × 事件係數
當日收入  = 來客×票價 + 來客×文創轉化(滿意度×人均基值) + 事件收入
劣化/日   = 材質基礎劣化 × 展櫃係數(1.0/0.7/0.45) × 環控係數 × 隱患加乘
修復恢復  = 工序完成度Σ × 正確率(工具/材料) × (1+技能加成) ，單次上限受病害清除數限制
```

### 11.3 節奏目標（平衡基準）

- 一天 8 分鐘內約可完成 1 次深度修復＋1–2 件館務操作 → 「永遠差一件事沒做完」的張力；
- 一季 30 天：全館藏約 8–12 件（含購藏），確保每件文物玩家都叫得出名字。
